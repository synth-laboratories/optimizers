Search loop

Parent selection is frontier-aware rather than a global argmax, which is what keeps a candidate that wins a single example alive.

  • Per-example scores are retained, so a regression on one example is visible instead of averaged away.
  • Reflection sees failure traces for the targeted module only.

Durability and protocol mapping

The v0.7 work: map the shipped service state onto the shared protocol, close the lossy resume paths, and add the uniform one-step operation.

  • 'RLVR-compatible' means a real observation/action/reward transition suitable for policy training. It does not mean relabelling prompt optimization.
